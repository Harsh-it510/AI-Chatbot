# 🤖 AI Chatbot with LLaMA 3.2, LangChain & Streamlit

This is a conversational AI chatbot web application built using **LLaMA 3.2** (via **Ollama**) and **LangChain**, with a clean front-end powered by **Streamlit**. The chatbot maintains conversation context and provides intelligent, helpful responses in real time.

---

## 🚀 Features

- ✅ Powered by **Meta's LLaMA 3.2** via Ollama
- ✅ Built with **LangChain** for prompt templating and chaining
- ✅ Context-aware conversation (retains history)
- ✅ Clean and interactive UI using **Streamlit**
- ✅ Easy to run locally, share, or deploy

---



## 🛠️ Technologies Used

- Python 3.x
- [LLaMA 3.2](https://ollama.com/library/llama3)
- LangChain
- Streamlit
- Ollama (local LLM inference)
